# Blank-editor exercise — BankAccount

Write a `BankAccount` class from scratch.

## State
- owner's name
- balance

## Requirements
- both fields are `private`
- `deposit(amount)` accepts only positive amounts
- `withdraw(amount)` accepts only positive amounts and cannot exceed the current balance
- `getBalance()` returns the balance
- `getOwner()` returns the owner's name
- choose an initial balance strategy that makes the object usable after construction

## Concepts exercised
- instance fields
- `private`
- parameters
- `this`
- methods
- return values
- encapsulation
- invariants

Do not copy a previous implementation; write it from a blank editor.
